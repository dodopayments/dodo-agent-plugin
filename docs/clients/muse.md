# Meta Muse Code

Muse Code (the `muse` CLI) loads this repository through its native manifest, [`.muse-plugin/plugin.json`](../../.muse-plugin/plugin.json), which is generated by `scripts/build.mjs` and lists every skill plus both MCP servers.

## Install as a plugin

Muse's plugin system is experimental and must be switched on:

```bash
export MUSE_EXPERIMENTAL_PLUGINS=1
muse plugins marketplace add dodopayments https://github.com/dodopayments/dodo-agent-plugin.git
muse plugins install dodopayments@dodopayments
muse plugins approve dodopayments
```

A plugin stays in `review_needed` until it is approved; its MCP servers are inactive until then.

Sign in to the API server:

```bash
muse mcp login dodopayments-api
```

## MCP servers without the plugin

Add to `~/.config/muse/settings.json`. `schema_version` is required — without it every command fails with `malformed settings file`. `mode: "optional"` keeps a network hiccup from aborting the whole run.

```json
{
    "schema_version": 1,
    "mcp_servers": {
        "dodopayments-api": {
            "transport": "streamable_http",
            "url": "https://mcp.dodopayments.com/mcp",
            "enabled": true,
            "mode": "optional"
        },
        "dodo-knowledge": {
            "transport": "streamable_http",
            "url": "https://knowledge.dodopayments.com/mcp",
            "enabled": true,
            "mode": "optional"
        }
    }
}
```

## Skills without the plugin

Muse Code reads `.agents/skills/` and `.claude/skills/` (project and user level), so `npx skills add dodopayments/dodo-agent-plugin` also works. Project skills load only after you trust the workspace.
